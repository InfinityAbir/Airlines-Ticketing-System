What this prototype demonstrates

Atomic booking

Exact-value payment, one seat reserved, one NFT minted, metadata CID recorded — all or nothing. A failed payment mints nothing.

Auditable lifecycle

Every state change emits an event (purchase, cancellation, refund, resale), so dashboards can be rebuilt straight from the chain.

No plaintext personal data

Ticket metadata is fictional and stored off-chain behind a CID; the chain and the public verifier only ever see wallet addresses and ticket state.
